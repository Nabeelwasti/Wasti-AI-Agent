# Android client

Native Kotlin + Jetpack Compose client with configurable HTTPS gateway, single/Hybrid request modes, and Android Keystore AES-GCM encryption for the gateway API key.

This is an initial connected client, not yet an offline-capable release. Local GGUF inference, model downloads, agent activity visualization, permission center and full encrypted memory remain release gates.

Open with Android Studio, JDK 17 and Android SDK 35. CI uses Gradle 8.9; no wrapper binary is committed yet.
